FnCPN 与直接公网端口暴露的比较
比较项FnCPN 私有网络直接公网端口暴露
安装与准备NAS 安装服务端，电脑安装客户端；启用 FN Connect 后授权连接。配置路由器或网关；直连通常需要可达的公网地址。经隧道转发则依赖额外服务。

访问对象适合自己、家人或团队成员，用各自的 fnOS 账号授权 Mac / Windows / Linux / Android 访问 NAS 和已启用的 LAN 网段；每台设备需要安装客户端。适合对外提供指定服务；是否需要客户端取决于服务，例如网页通常可直接用浏览器访问。

私有网络不替代服务自身的安全措施。请按需启用 LAN 网段，并保持 fnOS 与应用更新。

01

先安装 NAS 服务端

在 fnOS 应用中心手动安装对应架构的 FPK，打开 FnCPN，确认服务正常运行。

02

安装客户端

Mac、Windows、Android 按架构选择安装包；Linux 使用自动安装脚本，按桌面环境安装 UI 或无头 Core。

03

授权，然后连接

输入 FN Connect ID、fnOS 用户名和密码，按提示填写访问码或 OTP 并连接。Linux 客户端从 1.1.2 起提供。密码不会持久化保存。

04 / 你可能想知道

连接之前，
了解多一点。

阅读完整使用文档 ↗

故障排查与使用限制 ↗

需要公网 IPv4、自建中转或端口映射吗？＋

无需公网 IPv4、无需自建中转服务器，也无需为每个服务逐一配置端口映射。FnCPN 会选择局域网直达、IPv6 直连或 FN Connect 中继；实际可用路径取决于 NAS、FN Connect 和网络环境，中继速度取决于上游服务和网络条件。

普通 fnOS 用户可以使用吗？＋

普通用户可以连接。安装软件和修改服务端网络设置需要管理员权限。

支持访问码和两步验证（OTP）吗？＋

从 1.1.1 起，macOS、Windows 客户端和 Go CLI 均支持 fnOS 访问码和两步验证（OTP）。图形客户端在需要时显示访问码；提交账号密码后，若需 OTP，则进入独立步骤，可选择信任设备，也可返回上一步修改账号密码。

家人和团队成员怎么使用？＋

管理员先在 NAS 上安装并配置 FnCPN。每位成员在自己的电脑或 Android 手机安装客户端，用各自的 fnOS 账号授权连接，无需共享账号密码。请按实际需要设置 LAN 访问范围；私有网络连接不能替代 NAS 与内网应用自身的账号权限。

远程能访问哪些设备？＋

可以通过连接详情中的私有地址访问 NAS，也可以访问服务端启用的 LAN 网段。本地与远端网段重叠时会提示冲突，并保留 NAS 私有地址访问。

客户端和服务端必须同版本吗？＋

从 1.0.0 正式版起，MAJOR 必须相同，client MINOR 不得高于 server MINOR；PATCH 不参与准入判断。不兼容时按 App 提示升级对应端。

这是 fnOS 官方产品吗？＋

FnCPN 是采用 MIT 许可证的独立开源项目，与 fnOS、FN Connect 无隶属或背书关系。商标归各自权利人所有。
