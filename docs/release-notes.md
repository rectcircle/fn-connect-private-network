# FnCPN 1.0.0-rc.1

首个公开发布候选版，供首次安装与发布链路验证；不是正式 1.0.0。

- Apple Silicon macOS 13+ 客户端；fnOS x86_64 / ARM64 服务端。
- FN Connect 登录，自动选择 LOCAL / IPv6 DIRECT / RELAY；支持 NAS LAN 访问、网络配置同步与恢复。
- 统一版本准入、本地组件检查、离线设备管理、中英文界面及脱敏诊断。
- macOS App/helper 使用 ad-hoc 签名，PKG 未签名、未公证；安装需要管理员权限，系统可能要求明确批准。
- 图标改用项目绘制的存储圆柱；依赖许可证随包分发。

## 安装及升级

下载对应平台的安装包；先安装 fnOS 服务端，再安装 Mac 客户端。对照 SHA256SUMS 校验。
常规安装、覆盖升级和网络配置已有用户实机确认；本轮 RC 的专项实机验证尚未执行。
1.0.0 建立正式数据基线，不保证旧 0.x 历史格式迁移，不会自动清空身份或配置。
不支持旧格式时保留原数据，先备份并停止清理网络，再按明确范围重置和重新授权。
回滚须恢复旧程序与配套数据备份，不假定旧程序能读取新 schema。

## 已知限制

- ARM fnOS 和最低 macOS 支持版本未实机验证；权限负向验证暂缓，欢迎 issue 反馈。
- 本 RC 的卸载/purge、SIGKILL、无控制台用户安装及全新安装专项未执行。
- 不支持访问码、2FA、多服务端切换；离线设备删除不等于安全撤销。
- 中继速度受上游和网络影响；不宣称长期吞吐或性能验收通过。
- RC 到正式版本需更新安装包；稳定版 Homebrew Cask 等正式版发布后提供。
